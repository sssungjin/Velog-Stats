Velog Stats Release Notes

Velog Stats 확장 프로그램의 모든 버전 변경 사항을 확인하세요.

버전 1.9.2

주요 변경사항: 차트 데이터 안정성 강화 및 UI/UX 개선

  • 데이터 처리 개선
    • 차트 기능 업데이트 이전 버전에서 저장된 비정상적인 로그 데이터(undefined 등)가 있어도 차트가 깨지지 않도록 데이터 검증 로직(`sanitizeData`)을 추가했습니다.
    • 이제 모든 과거 로그 기록이 차트에서 누락 없이 표시됩니다. (비정상 값은 0으로 처리)
  • UI/UX 개선
    • 차트 뷰에 도움말 아이콘(?)을 추가하여, 클릭 시 차트 사용법 및 과거 데이터 표시에 대한 안내를 확인할 수 있도록 개선했습니다.

버전 1.9.1

주요 변경사항: 차트 Y축 표시 버그 수정

  • 버그 수정
    • 로그 데이터 값의 변화가 적을 경우, 차트의 Y축 눈금이 하나만 보이거나 0만 표시되던 문제를 해결했습니다.
    • Y축의 시작점을 항상 0으로 고정(`beginAtZero: true`)하여, 데이터 값에 관계없이 항상 적절한 범위의 눈금이 표시되도록 수정했습니다.

버전 1.9.0

주요 변경사항: 통계 성장 추이를 시각적으로 보여주는 차트 기능 추가 및 안정성 개선

  • 신규 기능: 차트 뷰 추가
    • 저장된 로그 기록을 바탕으로 조회수, 좋아요 수, 댓글 수의 성장 추이를 라인 그래프로 시각화합니다.
    • 차트 범례(Legend) 클릭을 통해 각 데이터(조회수, 좋아요 등)의 표시 여부를 토글할 수 있습니다.
  • UI/UX 개선
    • 차트 범례에 마우스를 올리면 포인터 커서로 변경하여 클릭 가능함을 시각적으로 안내합니다.
  • 버그 수정 및 안정성 향상
    • 최신 Chrome 브라우저 정책에 대응하여 쿠키 접근 권한 문제를 해결했습니다. (`manifest.json` 수정)

버전 1.8.1

주요 변경사항: 기능 변경 없음, 코드 리팩토링 및 구조 개선

  • 파일 분리: 기능별로 다음 파일들로 분리
    • popup.js
    • api.js
    • utils.js
    • logManager.js
  • 모듈 시스템 도입
    • 코드 재사용성 향상
    • 유지보수성 개선
  • UI: 게시물 별 통계 제목의 파란색 밑줄 제거
  • 설명서 상세화

버전 1.8.0

주요 변경사항: 로그 관리 기능 추가

  • Chrome Storage 활용
    • 조회한 로그 저장 기능
    • 저장된 로그 삭제 기능

버전 1.7.1

주요 변경사항: 기능 변경 없음, UI 개선

  • Web Store 이미지 변경

버전 1.7

주요 변경사항: 게시물 정렬 기능 추가 및 문구 개선

  • 게시물 정렬 기능
    • 조회수 기준 정렬
    • 댓글 수 기준 정렬
    • 좋아요 수 기준 정렬
  • 문법 상 어색한 문장 수정

버전 1.6

주요 변경사항: Velog 통계 기능 구현, access token 자동 추출로 사용자 경험 개선

  • 게시물 통계 제공
    • 조회수
    • 좋아요 수
    • 댓글 수
  • 모든 게시물에 대한 통계 한번에 불러오기 기능
  • chrome.cookie get API를 사용한 access_token 인증 과정 자동화

Demo 버전

주요 기능: Velog ID와 access token을 입력하여 통계 조회

  • 사용자 입력
    • Velog ID
    • Access Token
  • 통계 조회 기능
    • 입력된 ID와 token을 사용하여 Velog API 호출
    • 게시물 목록 및 각 게시물의 상세 통계 조회
  • 표시 정보
    • 총 게시물 수
    • 총 조회수
    • 총 좋아요 수
    • 총 댓글 수
    • 게시물 별 상세 통계 (제목, 조회수, 좋아요 수, 댓글 수)
