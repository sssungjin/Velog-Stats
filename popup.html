Velog Stats 설명서

Velog ID: 본인의 Velog ID를 입력하세요.

나의 ID 확인하기: Velog 로그인 > 내 벨로그 > url 확인 (velog.io/@{ID}/posts)

Velog를 로그인 후 Velog 사이트에서 프로그램을 실행시키면 access_token을 추출하여 api를 호출 하여 Velog의 통계를 볼 수 있는 Chrome Extension 입니다.

⚠️ 로그 데이터 보관 안내

조회된 통계 로그는 다른 서버가 아닌 사용자의 Chrome 브라우저에만 안전하게 저장됩니다. 다만, 아래의 경우에는 데이터가 삭제될 수 있으니 주의해 주세요.

  • 확장 프로그램을 삭제하는 경우: 프로그램을 Chrome에서 완전히 삭제하면 모든 로그 기록도 함께 영구적으로 삭제됩니다.
  • 브라우저 데이터를 삭제하는 경우: Chrome의 '인터넷 사용 기록 삭제' 기능으로 '쿠키 및 기타 사이트 데이터'를 청소하면 로그가 지워질 수 있습니다.
